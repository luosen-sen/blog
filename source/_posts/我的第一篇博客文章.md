## 发一篇文章有多简单

终端里执行这一行，Hexo 会自动在 `source/_posts/` 目录下生成一个新的 Markdown 文件，文件名就是你的标题：

```bash
npm new "文章标题"
```

然后用任何编辑器打开 `source/_posts/文章标题.md`，把正文写好，存盘。

写完先本地看看效果：

```bash
npm run dev
```

浏览器打开 <http://localhost:4000> 就能实时预览（改完文件自动刷新）。

满意了就生成最终页面并部署：

```bash
npm run build
```

## 文章开头的 front-matter

每篇文章最上面那一块 `--- ... ---` 叫 front-matter，用来描述这篇文章的元信息。常用字段：

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| `title` | 文章标题 | `我的第一篇博客文章` |
| `date` | 发布时间 | `2026-10-01 20:00:00` |
| `tags` | 标签，可写多个 | `- 建站` |
| `categories` | 分类，可写多个 | `- 建站笔记` |
| `cover` | 封面图 | `/img/default_cover.svg` |
| `top` | 置顶，数字越大越靠前 | `top: 1` |
| `sticky` | 同置顶 | `sticky: 100` |

## 支持的 Markdown 语法

正文全部用 Markdown 写，支持：

- **加粗**、*斜体*、~~删除线~~
- 列表、表格、任务清单
- `行内代码` 和代码块（可标注语言）
- 图片：`![图片说明](/img/default_cover.svg)`
- 引用、分割线
- 数学公式（Butterfly 默认开启）

```js
function hello(name) {
  console.log(`你好，${name}！`);
}
hello('新博客');
```

> 小提示：在正文里插入 `<!-- more -->`，它前面的内容会作为首页摘要显示。
