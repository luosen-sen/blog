## 日常写文章的三条命令

```bash
npm new "标题"    # 新建文章，生成 source/_posts/标题.md
npm run dev       # 本地预览，http://localhost:4000
npm run build     # 生成最终网页到 public/ 目录
```

草稿箱：`npm new draft "标题"` 会生成到 `source/_drafts/`，这个目录下的文章**不会**被发布，用来放没写完的东西。想本地预览草稿要执行 `npm run dev --draft`。

## 图片放哪里

所有图片都放进 `source/img/`，然后在 Markdown 里这样引用：

```markdown
![这张图片的说明](/img/我的图片.jpg)
```

注意路径以 `/img/` 开头，是站点根目录的相对路径，不要写 `D:\博客\source\img\...` 这种本地路径。

- `source/img/avatar.jpg` —— 左上角头像，在 `_config.butterfly.yml` 的 `avatar.img` 里改
- 其他图片随意命名

## 想换头像、换颜色、改菜单

打开 [_config.butterfly.yml](_config.butterfly.yml)，这些都是常用的：

```yaml
avatar:
  img: /img/avatar.jpg      # 头像图片

nav:                        # 顶部菜单
  首页: / || fas fa-home
  关于: /about/ || fas fa-heart

social:                     # 社交图标
  fab fa-github: https://github.com/luosen-sen || Github
```

Butterfly 的完整配置项有几百个，官方文档在这里：<https://butterfly.js.org/posts/4aa8abbe/>。改完记得重新 `npm run build`。

## 「关于」页面怎么写

```bash
npm new page "关于"
```

会生成 `source/about/index.md`，菜单里的「关于」就自动有内容了。

## 文章置顶

在 front-matter 里加一行，数字越大越靠前：

```yaml
top: 1
```

## 上传到 GitHub Pages 部署

仓库里已经配好 `.github/workflows/deploy.yml`，你把代码推到 GitHub 的 `main` 分支，它就会自动生成网页并发布。流程是：

```bash
git add .
git commit -m "更新博客"
git push
```

第一次用要先在 GitHub 网页上把仓库的 **Settings → Pages → Build and deployment → Source** 选成 `GitHub Actions`。详见 [README.md](README.md)。

## 常见问题

**改了内容但网站没变化？** 执行一次 `npm run clean` 再 `npm run build`，Hexo 的缓存偶尔会作怪。

**预览时中文标题的网址打不开？** 正常，Hexo 会做转码，不影响线上访问。

**想改网站标题和副标题？** 在 [_config.yml](_config.yml) 最上面的 `title` / `subtitle` / `author`。
